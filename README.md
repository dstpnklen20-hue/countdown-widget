# Обратный отсчёт — виджет для Android

Минималистичное Android-приложение с настраиваемым виджетом на главный экран:
показывает обратный отсчёт времени до заданной даты (дни/часы/минуты).
Работает на телефонах и планшетах (Android 8.0+).

## Возможности

- Список отсчётов внутри приложения с живым таймером (обновляется каждую секунду).
- Настраиваемый виджет на главный экран: при добавлении виджета выбираете
  существующий отсчёт или создаёте новый прямо на месте.
- Можно добавить сколько угодно виджетов — каждый со своей датой.
- Тап по виджету открывает редактирование его отсчёта (название, дата и время).
- Экран настроек (кнопка с шестерёнкой слева внизу): тема светлая/тёмная/системная, акцентный цвет и 14 готовых цветовых тем (в стиле Obsidian).
- Виджет 2×1 с автоподбором размера текста; цвета виджета берутся из выбранной темы.
- Виджет переживает перезагрузку устройства.

## Почему нет готового .apk

Я собрал полный исходный код проекта, но не смог скомпилировать APK в этой
изолированной среде: здесь нет Android SDK, а сеть в песочнице блокирует
скачивание `dl.google.com`, откуда берутся Android SDK и AndroidX-зависимости.
Сборка занимает 2–3 минуты на обычном компьютере с Android Studio — см. ниже.

## Как собрать без Android Studio (через GitHub Actions)

Если Android Studio скачать не получается, можно собрать APK в облаке —
локально ничего тяжёлого ставить не нужно, только Git. Все команды ниже
можно выполнять из терминала VSCodium (**Terminal → New Terminal**).

1. Зарегистрируйтесь на [github.com](https://github.com) (бесплатно), если
   ещё нет аккаунта. Создайте новый пустой репозиторий, например
   `countdown-widget` (кнопка **New repository**, без README).
2. В терминале VSCodium перейдите в папку проекта и отправьте код:
   ```bash
   cd путь/к/CountdownWidget
   git init
   git add .
   git commit -m "Countdown widget app"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/countdown-widget.git
   git push -u origin main
   ```
   (Git должен быть установлен на компьютере — если команда `git` не
   найдена, поставьте [Git](https://git-scm.com/downloads), это лёгкий
   установщик, ~50 МБ.)
3. Откройте репозиторий на github.com → вкладка **Actions**. Сборка
   (`Build APK`) запустится автоматически после `push` и займёт 2–4 минуты.
4. Когда сборка завершится (зелёная галочка), откройте её и внизу страницы
   в разделе **Artifacts** скачайте `countdown-widget-debug-apk.zip`.
5. Распакуйте — внутри `app-debug.apk`. Перенесите файл на телефон
   (например, через облако/почту/USB) и установите (может потребоваться
   разрешить установку из неизвестных источников в настройках Android).

Дальше при любой правке кода достаточно повторить `git add . && git commit -m "..." && git push` — сборка обновится сама.

## Альтернатива: собрать локально из VSCodium

Тоже возможно, но потребует установить на компьютер Android SDK
command-line tools и JDK 17 отдельно (без графической Android Studio) —
дайте знать, если хотите такую инструкцию: там больше шагов и своя загрузка
SDK (~1–1.5 ГБ), поэтому вариант с GitHub Actions обычно проще.

## Как добавить виджет на главный экран

1. Установите приложение (см. выше).
2. Долгое нажатие на пустом месте главного экрана → **Виджеты**.
3. Найдите «Обратный отсчёт», перетащите на экран.
4. В открывшемся окне выберите существующий отсчёт или нажмите
   «+ Новый отсчёт», задайте название и дату/время.
5. Виджет готов. Тап по нему открывает редактирование этой даты.

Виджет обновляется автоматически примерно раз в 15–30 минут (это ограничение
самой системы Android для экономии батареи, а не приложения) — этого
достаточно для отображения дней/часов. Открыв само приложение, вы увидите
точный отсчёт с секундами в реальном времени.

## Структура проекта

- `MainActivity` — список отсчётов внутри приложения.
- `EditCountdownActivity` — создание/редактирование/удаление отсчёта.
- `widget/CountdownWidgetProvider` — логика самого виджета.
- `widget/WidgetConfigureActivity` — экран настройки при добавлении виджета.
- `data/CountdownRepository` — хранение данных (SharedPreferences).
