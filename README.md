# Tik Tak — менеджер задач для Android

Менеджер задач в духе TickTick, выросший из приложения «Обратный отсчёт».
Работает офлайн, на телефонах и планшетах (Android 8.0+). При обновлении со старой
версии все отсчёты и виджеты переносятся автоматически.

## Возможности

- **Задачи**: название, описание, 4 уровня приоритета, дата и время, подзадачи, чек-лист, теги.
- **Списки и папки**, умные списки: Входящие, Сегодня, Завтра, 7 дней, Все, Отсчёты, Выполненные.
  Группировка по датам, свайп вправо — выполнить, влево — удалить.
- **Быстрый ввод** на русском и английском: `завтра в 10 позвонить !высокий #работа ~Дом`,
  `каждый понедельник планёрка`, `через 2 часа выключить духовку`, `call mom tomorrow at 5pm`.
- **Повторы**: ежедневно, по дням недели, по будням, ежемесячно (число, последний день,
  «второй понедельник»), ежегодно, интервалы, окончание по дате или количеству, «от даты выполнения».
- **Напоминания** с кнопками «Выполнено», «+15 мин», «+1 час»; переживают перезагрузку.
- **Обратный отсчёт** как режим отображения любой задачи.
- **Календарь**: день, 3 дня, неделя, месяц, год, смена свайпом; будущие повторы видны заранее.
- **Сортировка** любого списка: по дате, приоритету, названию, сначала новые (меню «⋮»).
- **Панель инструментов** как в TickTick: свои разделы и их порядок, лимит вкладок, меню «Ещё»;
  на планшете — боковая колонка со всеми разделами.
- **Синхронизация** между устройствами через аккаунт (Supabase) и **резервная копия** в файл.
- **Корзина** и «Отменить» после удаления.
- **Канбан** для любого списка (колонки = разделы) и **матрица Эйзенхауэра**.
- **Pomodoro** со статистикой за день, неделю и всё время.
- **Привычки**: дни недели, цель в день, серии, календарь выполнения, напоминания.
- **Виджеты**: «Сегодня» (с галочками), «Быстро добавить», «Обратный отсчёт».
  Добавить их можно из Настроек → «Добавить виджет на рабочий стол».
- Темы: светлая/тёмная/системная, акцентный цвет, 20 готовых цветовых тем; у виджетов может быть своя.

## Сборка через GitHub Actions

Сборка идёт в облаке при каждом `push`; локально нужен только Git.

- Ветка `main`: CI прогоняет тесты, собирает APK и публикует релиз `build-N`,
  который приложение само предлагает установить (см. «Автообновление»).
- Любая другая ветка (например, `tasks`): только тесты и APK-артефакт
  `tik-tak-debug-apk` в разделе **Artifacts** запуска, без публикации пользователям.

## Автообновление

Каждая сборка из `main` публикуется как релиз `build-N` (номер = `versionCode`).
Приложение при запуске (и по кнопке в настройках) проверяет последний релиз, скачивает
новый APK и предлагает установить его поверх текущей версии — данные и виджеты сохраняются.
APK подписывается постоянным ключом из GitHub Secrets (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`,
`KEY_ALIAS`, `KEY_PASSWORD`); без этих секретов релиз не публикуется.

Нельзя менять (иначе обновление не встанет поверх или пропадут виджеты): `applicationId`
`com.claudecode.countdown`, ключ подписи, имена классов `MainActivity` и
`widget.CountdownWidgetProvider`.

## Структура проекта

- `core/` — чистый Kotlin: парсер быстрого ввода (`QuickAddParser`) и движок повторов (`RepeatRule`).
- `app/.../data/` — Room (сущности с UUID, `updatedAt` и флагом удаления для будущей синхронизации),
  DAO, миграции, репозитории; `DatabaseSeeder` переносит данные старой версии.
- `app/.../domain/` — умные списки, повторы, напоминания, календарь, статистика привычек.
- `app/.../ui/` — экраны на Jetpack Compose.
- `app/.../reminders/`, `pomodoro/`, `widget/` — будильники, уведомления, виджеты.
- `app/.../data/sync/` — резервная копия и синхронизация (все записи — JSON в одной таблице Supabase).
- `app/schemas/` — экспорт схем Room: при изменении базы нужна новая версия и явная миграция.
- `supabase/schema.sql` — таблица, триггер и правила доступа на сервере (выполняется в SQL Editor).

## Локальная разработка

Нужны JDK 17 и Android SDK (platform 34). Тесты: `./gradlew :core:test :app:testDebugUnitTest`,
APK: `./gradlew assembleDebug`.
