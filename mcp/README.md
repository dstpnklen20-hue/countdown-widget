# Коннектор Tik Tak для Claude

Небольшая программа (MCP-сервер), через которую Claude работает с вашими задачами и событиями Tik Tak.
Она входит в тот же аккаунт, что телефон и сайт. Изменения сразу уходят на сервер, и телефон получает их
при следующей синхронизации.

Что умеет Claude с коннектором:

| Инструмент | Что делает |
|---|---|
| `tiktak_overview` | списки, календари, теги |
| `tiktak_agenda` | расписание по дням: задачи и события, повторы, просроченное |
| `tiktak_tasks` | задачи по разделам: Входящие, Сегодня, 7 дней, без даты, выполненные, по списку или тегу |
| `tiktak_search` | поиск по словам |
| `tiktak_get` | подробности: описание, подзадачи, чек-лист, напоминания |
| `tiktak_quick_add` | задача одной фразой: «завтра в 10 позвонить маме !высокий #семья» |
| `tiktak_create_task`, `tiktak_create_event` | задача или событие с точными датой и временем |
| `tiktak_update` | изменить название, дату и время, список, приоритет, теги, повтор |
| `tiktak_complete` | отметить выполненной (повторяющаяся переходит к следующему разу) |
| `tiktak_delete` | в корзину (можно вернуть в приложении); один день повторяющегося события |
| `tiktak_checklist_add` | пункты чек-листа |

## Установка (один раз)

Нужен Node.js 20 или новее. В PowerShell:

```powershell
cd "F:\Tik Tak app\mcp"
npm ci
npm run build
```

## Вход в аккаунт

```powershell
node "F:\Tik Tak app\mcp\dist\tiktak-mcp.mjs" login
```

Программа спросит почту и пароль. Пароль на экране не отображается и не сохраняется. Сохраняется только
ключ входа в `%APPDATA%\tiktak-mcp\session.json`. Другие команды: `status` (кто вошёл), `logout` (выйти).

## Подключение к Claude

Проще всего одной командой. Сначала **полностью закройте Claude Desktop** (значок у часов → Quit), потом:

```powershell
node "F:\Tik Tak app\mcp\dist\tiktak-mcp.mjs" install
```

Команда добавит коннектор и в Claude Code, и в чат Claude Desktop, а копии прежних настроек сохранит рядом
с ними (`*.before-tiktak`). Закрывать Claude нужно потому, что при выходе он записывает свои настройки
поверх файла и убирает из него всё, что добавлено, пока он работал.

Вручную:

**Claude Code** (вкладка Code в приложении Claude): добавьте в файл `C:\Users\<вы>\.claude.json`, в раздел
`"mcpServers"` (если раздела нет, создайте его на верхнем уровне):

```json
"tiktak": {
  "type": "stdio",
  "command": "node",
  "args": ["F:\\Tik Tak app\\mcp\\dist\\tiktak-mcp.mjs"]
}
```

**Чат Claude Desktop**: Settings → Developer → Edit Config. В открывшийся `claude_desktop_config.json`
добавьте то же самое внутрь `"mcpServers": { ... }` (без строки `"type"`) и полностью перезапустите приложение.
Если `node` не находится, укажите в `"command"` полный путь: `"C:\\Program Files\\nodejs\\node.exe"`.

После перезапуска спросите Claude: «что у меня сегодня в Tik Tak?»

## Для разработки

- `npm test` — проверка всех инструментов на поддельном сервере в памяти (настоящий аккаунт не трогается).
- Код задач и дат общий с сайтом (`web/src`). Правила записи описаны в `CLAUDE.md` в корне репозитория.
